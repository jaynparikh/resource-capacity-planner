# 🚀 Resource Capacity Planner

A modern **Resource Capacity Planning** application built using **React**, **Node.js**, **Express**, **PostgreSQL**, **Prisma ORM**, and **Google Gemini AI**.

The application helps engineering managers and delivery leaders efficiently manage employees, projects, resource allocations, and team capacity while leveraging AI-powered insights for smarter decision-making.

---

# ✨ Features

### Dashboard
- Resource utilization overview
- Capacity summary
- Key metrics
- Visual insights

### Employee Management
- Add, edit and delete employees
- Manage skills and roles
- Track employee capacity
- Employee availability status

### Project Management
- Create and manage projects
- Track project status
- Client information

### Resource Allocation
- Assign employees to projects
- Update allocation percentages
- Prevent resource conflicts

### Capacity Planning
- Capacity utilization dashboard
- Available vs allocated capacity
- Resource planning overview

### Reports
- Resource utilization reports
- Capacity summary
- Employee workload overview

### Settings
- Company settings
- Working hours
- Default employee capacity

### 🤖 AI Resource Planning Assistant
Powered by **Google Gemini 2.5 Flash**

Ask business questions like:

- Who has available capacity?
- Which employees are overallocated?
- Summarize current resource utilization.
- Recommend resources for new projects.
- Suggest better allocation strategies.

# ⚙ Installation

## Clone repository

```bash
git clone <repository-url>
```

## Backend

```bash
cd server
npm install
```

## Frontend

```bash
cd client
npm install
```

---

# 🔐 Environment Variables

Create a `.env` file inside the **server** folder.

```env
DATABASE_URL=your_database_connection

GEMINI_API_KEY=your_gemini_api_key
```

---

# ▶ Running the Application

Backend

```bash
npm run dev
```

Frontend

```bash
npm run dev
```
